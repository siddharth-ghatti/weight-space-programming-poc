## Objective

**Make the model as small as possible while keeping its accuracy.** The final checkpoint is scored on
the same held-out test set. It passes if its test accuracy is at least **97.8%**; a
submission below that fails regardless of size. Among passing models, fewer exported parameters is
better. You never see the test set; cross-validation on the practice set is your proxy, so leave
margin.

## What counts as smaller

The exported checkpoint must load with stock `transformers`, so only two things shrink it:

1. **Dropping encoder layers.** You keep an ordered subset of the original layers 0..11; the harness
   renumbers them 0..k-1 and sets `num_hidden_layers = k`.
2. **Narrowing the feed-forward blocks.** For every kept layer you choose which m of its 3,072
   intermediate units survive; the harness slices `intermediate.dense.weight/bias` (rows) and
   `output.dense.weight` (columns) and sets `intermediate_size = m`. Stock BERT has a single
   `intermediate_size`, so **every kept layer must keep the same number m of units** (which units can
   differ per layer). `output.dense.bias` and both LayerNorms of a kept layer stay at full size.

Exported parameters = 24,433,928 + k · (2,366,208 + 1,537 · m). The fixed part is
the frozen embeddings (23,837,184), the pooler and the classifier, so it is the floor.
Attention heads cannot be removed from a stock checkpoint: zeroing a head, a unit or a layer that
remains in the structure saves nothing. The hidden size, the vocabulary and the embeddings stay as
they are.

## How the edited model is built

Your saved tensor edits are always at the full original shapes (diffs against the start model). The
*edited model* used by every forward pass and by the final export is: start model + your saved edits,
then the kept layers in `structure.json` renumbered and their FFN units sliced. Edits to layers you
drop have no effect. In forward passes, `model: "base"` is the unpruned 12-layer start model and
`model: "edited"` is your pruned model; hidden-state indices of the edited model run 0..k and the pass
result includes `layer_map` (edited index -> original layer id). The last kept layer's output
LayerNorm feeds the pooler.

## The starting model

What the previous editor changed, in its own words (its edits are already in the start weights):

I turned BERT into the insurance classifier using only closed-form math: ridge regressions fit on hidden states of practice sentences, then written directly into the weights. Nothing was trained iteratively.

**Expected accuracy:** about 97.8% on new sentences, from 5-fold out-of-fold cross-validation (5-fold CV) on the practice set. The final model gets 100% on all 1496 practice sentences, but the head was fit on those same sentences, so that number only shows the edits work as designed. It says nothing about the test set.

**What I found first:** I read hidden states from every layer for all practice sentences. The average over all tokens at any layer separates the 8 labels much better than the [CLS] vector does: about 96% with a ridge classifier. Combining an early, a middle and a late layer reached about 97.8–97.9%.

**How the edit works:**
1. **A reserved channel.** I set aside 8 of the 768 hidden dimensions to hold class evidence. At the end of layer 1, I zero their LayerNorm scale and shift so they start empty. In layers 2–10 I cut every read and write of those 8 dimensions, so the rest of the network behaves as before and nothing disturbs the channel.
2. **Carry heads in layers 2, 6 and 10.** In each of these layers I repurposed one attention head. Its query is zero, so it attends equally to every token and effectively computes the average token vector. Its value and output weights turn that average into 8 ridge scores (one per label), added into the reserved dimensions. A small gain keeps those dimensions from upsetting LayerNorm.
3. **Layer 11 as a pooling layer.** I rewrote its attention so [CLS] receives roughly 2 × (average of layer-11 token states) + its own state, with the feed-forward output turned off. The final [CLS] vector therefore holds the late-layer average plus the 8 carried scores.
4. **Pooler and classifier.** Pooler rows 0–7 equal 0.5 × [ridge weights on the final [CLS] vector + a decode of the reserved channel]. The decode subtracts the channel's mean across the 8 dimensions, because LayerNorm adds a shared offset to all of them. The classifier simply selects pooled dimensions 0–7. Since tanh is monotonic, the predicted label is the argmax of the ridge score, and the tanh outputs stay well short of saturating (they range from -0.11 to 0.55).

**How I fitted the weights:** First I installed the carry heads and the aggregation layer. Then I read the edited model's real activations and fitted one joint ridge (penalty 300, selected by cross-validation) on the three carried layer averages and the final [CLS] vector. The fit used each sentence's measured carry scale, so it matches how the network actually behaves.

**Checks:** Running all 1496 practice sentences through the edited model gave outputs equal to my numpy prediction (tanh of 0.5 × ridge score) to within about 1e-4 (2e-4 on the first read, 8e-5 on the second). Every prediction was correct, and the smallest top-1 margin was 0.175.

**Bug found and fixed:** An earlier version ignored the shared offset in the reserved dimensions. That saturated tanh and dropped accuracy to 51%; the mean-subtracting decode in step 4 fixed it.

## Rules

1. **No training.** No backward passes, autograd, optimizers, or iterative fitting of any kind.
   Closed-form math on weights, and on activations returned by forward passes, is allowed.
2. **Do not run the model inside the sandbox.** Forward computation happens only through the
   `forward_pass` tool. (The sandbox has no torch or transformers; reimplementing the forward pass in
   numpy is also forbidden.)
3. **Editable tensors:** everything under `bert.encoder.*`, `bert.pooler.*`, and `classifier.*`.
   `bert.embeddings.*` is frozen.
4. No internet. Each sandbox run is a fresh process; only files in the working folder persist.
5. Explain your reasoning in plain English in your messages as you go; keep running notes in
   `notes.md` in the working folder (they are given back to you if the conversation is restarted).
6. **No self-authored data.** The only labeled or unlabeled text you may use is `practice.jsonl`.
   Do not write your own example sentences, paraphrases, keyword or phrase lists, or any other text
   and use it to fit, calibrate, select, or check weights. `forward_pass` accepts practice ids only.
   Your deliverable is tensor edits and a structure computed from the provided weights, the practice
   set, and activations of practice sentences.

## Budget

- Forward passes: **50** in total. Each `forward_pass` call that succeeds costs 1, whatever its size.
- Code runs: **300** in total.
- When passes are exhausted you may keep editing with code, then call `submit`.
- Every 40 turns the conversation is restarted with a handoff (task, your notes.md,
  your current edits and structure, remaining budget).

## Tools

- `run_python(code)`: run Python in the sandbox.
- `forward_pass(...)`: predict on practice sentences, or read hidden states / pooled output / logits /
  attention for practice sentences chosen by id, on the base or the edited (pruned) model. Results
  land in `pass_<k>/` in the working folder.
- `submit(final_answer)`: finish; your saved edits plus `structure.json` are the final model.

## Sandbox prelude

Every code run starts with a prelude that defines (numpy is imported as `np`):

- `catalog()` -> list of {name, shape, editable, in_model} for every tensor of the start model.
- `base(name)` -> float32 copy of the START model's tensor (the model you are shrinking), full shape.
- `W(name)` -> the current tensor at full shape: your saved edit if one exists, else the start tensor.
- `save_edit(name, array)` -> validates (editable, exact FULL shape, finite) and saves to `edits/<name>.npy`.
  Saving the same name again overwrites. Edits are always at the full original shape; the harness
  slices kept FFN units and renumbers kept layers when it builds the edited model and the export.
- `drop_edit(name)`, `edits()` -> manage/list saved edits.
- `practice()` -> list of {id, text, label} practice sentences (also at `practice.jsonl`).
- `tokenize(texts)` -> [{ids, tokens}] using the model's WordPiece tokenizer (uncased).
- `vocab()` -> token -> id dict.
- `pass_dirs()` -> folders of completed forward passes; see each folder's files.
- `WORK` -> Path of the persistent working folder (cwd). Write notes, files, arrays freely.
- `LABELS`, `NUM_LABELS`, `HIDDEN`, `NUM_LAYERS` (12), `FFN` (3072) constants.

Each run is a fresh process; only files in the working folder persist between runs.
Available packages: numpy, scipy, safetensors, tokenizers, and the standard library. No torch, no
transformers, no network.


Structure helpers (the pruning spec lives in `structure.json` in the working folder):

- `structure()` -> {layers, m, ffn_keep}: original layer ids kept (in order) and, per kept layer,
  the sorted ids of the FFN units kept. Default: all 12 layers, all 3072 units.
- `set_structure(layers=None, ffn_keep=None)` -> writes `structure.json` and returns the resulting
  parameter count. `layers`: original ids to keep, strictly increasing. `ffn_keep`: an int m (units
  0..m-1 everywhere), a list of unit ids (same everywhere), or {layer: [unit ids]}; every kept layer
  must keep the same number m of units. The edited model used by forward passes and by the final
  export is: start + your saved edits, then kept layers renumbered 0..k-1 and FFN units sliced.
- `clear_structure()`, `kept_units(layer)`, `param_count(struct=None)` -> exported parameter count.

Parameter accounting of the exported checkpoint (stock `BertForSequenceClassification`):
  total = 24,433,928 + k * (2,366,208 + 1,537 * m)
  where k = layers kept, m = FFN units kept per layer; the fixed part is the embeddings
  (23,837,184, frozen and never pruned), the pooler (590,592) and the classifier
  (6,152). The full model is 109,488,392.
Slicing FFN unit i removes row i of `intermediate.dense.weight`/`bias` and column i of
`output.dense.weight`; `output.dense.bias` and both LayerNorms of a kept layer stay at full size.
Attention heads cannot be removed from a stock checkpoint: zeroing a head saves nothing.
